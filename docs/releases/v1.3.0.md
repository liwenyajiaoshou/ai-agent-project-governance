# v1.3.0 — Optional Context Handoff

Coding Agent Governance v1.3.0 adds Context Handoff 0.1.0 as an optional extension for long-running projects that move between Codex threads.

## Highlights

- A task-specific current-state view and handoff entry.
- A deterministic multi-task document index.
- Schema-checked snapshots based only on explicit structured evidence.
- Preview, enable, disable, and uninstall commands designed to preserve generated history and user-modified files.

## Compatibility

- Context Handoff is disabled by default.
- Core-only behavior remains unchanged and does not depend on the extension.
- The extension does not access external systems, APIs, databases, telemetry, or user files outside its explicit target directory.
